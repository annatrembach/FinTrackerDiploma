# Financial Goals

## What is a goal?
A goal is a savings target with a name, target amount, and deadline.
You track progress by adding funds towards the goal over time.

## Creating a goal
Required fields:
- **name**: descriptive name (e.g., "Vacation fund", "New laptop")
- **targetAmount**: how much you want to save
- **deadline**: target date in ISO-8601 format

Example: "Create a goal to save 5000 for vacation by December 2024"

## Viewing goals
- "Show all my goals" — lists every goal
- "Show active goals" — only IN_PROGRESS goals
- "Show completed goals" — only COMPLETED goals

Goal statuses:
- **IN_PROGRESS** — actively saving
- **COMPLETED** — target amount reached
- **CANCELLED** — manually cancelled

## Updating a goal
You can change the name, target amount, or deadline.
Example: "Update goal 3 change deadline to March 2025"

## Completing a goal
Mark a goal as completed when you've reached your target.
Example: "Mark goal 5 as complete"

## Deleting a goal
Example: "Delete goal 3"
This permanently removes the goal and its history.
